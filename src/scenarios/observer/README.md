# Сценарий Observer

`scenario.json` задаёт историю, классы, поля, методы, связи, подсказки, позиции и локальные иллюстрации. Общая инфраструктура строит редактор, проверяет диаграмму, хранит историю и показывает решение. Регистрация сценария и демонстрации выполняется автоматически.

Код в этом каталоге отвечает только за демонстрацию:

- `Demo.tsx` хранит подписку Narion и текущий запуск, получает `ConfiguredDemoProps` и сбрасывает результат при изменении графа.
- `NotificationDemo.tsx` показывает уведомления, переключатель браслета, анимацию и трассу вызовов. Таймеры приостанавливаются у скрытого сценария.
- `demoModel.ts` вычисляет результат обнаружения опасности и проверяет входную диаграмму общим валидатором на основе `scenario.json`.
- `demoModel.test.ts` проверяет опасность, безопасный путь, отписку, трассу и запрет запуска неверной диаграммы.
- `styles.css` содержит только стили демонстрации с областью `.observer-scenario`.
- `resource/` содержит изображения урока.

Для изменения урока редактируйте `scenario.json`; для изменения поведения уведомлений — файлы демонстрации. Проверки: `npm run test:observer`, `npm run test:configs`, `npm run typecheck`, `npm run build`.
